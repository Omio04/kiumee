# 키오스크 인식 개선 및 main 통합

2026-11-12 기준. 사용자 제공 `kiumee-main (1).zip`은 GitHub main `a8ca534`와 줄바꿈을 정규화하여 비교했을 때 파일 내용이 동일했다. 해당 main 위에 P2 개선 중 `vision/`만 통합했다. 팀원의 카메라 이동 보정, 가격 OCR 흔들림 대응, 장바구니 중복 처리 및 앱 조립을 유지했다.

## 개선 동작

- 제목 하나로 결제 완료를 추측하지 않는다. 카드 승인 요청, 승인 중, 영수증, 완료 화면은 실제 제목과 아래쪽 행동·주문 번호 등 추가 근거를 함께 확인한다.
- 상위 팝업의 제목만 일부 읽힌 경우 뒤쪽 주문 화면을 활성 화면으로 확정하지 않는다. 배경 버튼과 이전 프레임의 버튼 후보를 다시 살리지 않는다. 확실하지 않은 화면은 미분류로 남긴다.
- 화면 종류와 옵션 요약의 변경은 두 관측이 일치해야 전환으로 확정한다. 요약 OCR이 누락된 것만으로 사용자 선택이 초기화되었다고 판단하지 않는다.
- 작은 닫기 X의 밝기 샘플 위치를 픽셀 중심에 맞추고 짧은 대각선도 검사한다. 실제 가짜 키오스크 캡처의 X와 기존 키오스크 사진으로 회귀 검증했다. 더하기, 원, 작은 반사점은 후보에서 제외한다.
- 긴 제목의 한 글자 오차는 화면 판단에만 허용한다. 실제 OCR 텍스트를 메뉴 사전으로 대체하지 않는다. 맛·샷·매장/포장·일회용품·결제수단은 사용자가 선택한다.

공용 모델·포트·JSON 필드와 `sN` 화면 ID 형식은 그대로다. ML Kit 엔진도 그대로 사용한다. 이 변경은 관측 결과의 후처리·전환 판단 개선이며 모델 가중치 재학습은 아니다.

## 검증

main의 실제 `:core-model` 및 Android 빌드 설정으로 아래 검증을 실행했다.

```bash
./gradlew :vision:testDebugUnitTest :vision:lintDebug :core-model:test :domain:test \
  :voice:testDebugUnitTest :agent:testDebugUnitTest :overlay:testDebugUnitTest \
  :app:testDebugUnitTest :app:assembleDebug
```

전체 229개 테스트 중 228개 통과, 로컬 사진이 필요한 선택적 테스트 1개는 건너뛰었다. 이어 해당 원본 사진을 제공하여 `CloseIconDetectorTest` 4개를 다시 실행했고 모두 통과했다. Lint 오류는 없으며 기존 UseKtx 경고 2개가 있다. 팀 앱 debug APK 빌드도 통과했다.

`testdata/kiosk/ocr-replay.json`의 실제 Tesseract 관측 15개를 재생하여 잘못된 화면으로 분류하지 않는지, 불완전한 팝업 뒤의 버튼이 노출되지 않는지 검사한다. 판독이 불충분하면 미분류가 허용된다. 이 결과는 Android ML Kit의 실기기 글자 인식률 측정값이 아니다.

실기기의 회전·반사·카메라 거리별 ML Kit 인식률, 처리 시간, 안내 흐름은 별도 측정해야 한다. 실험용 Tesseract 전처리나 별도 웹 데모는 이번 main 통합에 포함하지 않았다.
